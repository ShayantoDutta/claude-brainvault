# How to use your Inbox

This folder is where you drop new information for Claude to learn.

## How it works

1. Drop any file, note, or content into this folder
2. Open a Claude session
3. Say: **"process my inbox"**
4. Claude reads what's here, extracts what's useful, adds it to the right hub, and cross-links it

That's it.

## What to drop here

- New documents you want Claude to know about
- Notes from meetings or conversations
- Research you've done
- Updates to projects Claude already knows about
- New context that's changed since you set up your brain

## What NOT to drop here

- Files with passwords, API keys, or tokens
- Files with other people's private data
- Massive files (over 50MB) — describe the key points instead

## After processing

Processed files get moved to `06_archive/` automatically. Your hubs get updated with the new context.
